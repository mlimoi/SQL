# SQL and Database Projects

## Overview

This repository showcases the SQL and database projects I completed during my **Data Technician Skills Bootcamp**. The work demonstrates my ability to design relational databases, write SQL queries and analyse business and demographic data using **MySQL Workbench**.

## Projects Completed

### Northwind Business Analysis

Used the Northwind database to answer realistic business questions involving customers, products, suppliers, employees and orders.

* Retrieved and filtered customer, product and order data.
* Identified high-value products and recent orders.
* Connected products with their categories and suppliers.
* Combined customer, employee and order information into detailed reports.
* Calculated product totals by category using aggregate functions.
* Analysed sales quantities, prices and yearly order activity.

### World Database Analysis

Used the World database to analyse countries, cities, populations and life expectancy.

* Identified the most and least populated cities and countries.
* Compared cities using population ranges and rankings.
* Analysed city-name patterns using `LIKE`.
* Calculated city-name frequencies with `COUNT` and `GROUP BY`.
* Connected country and city tables to identify capitals and European cities.
* Sorted, filtered and limited query results to produce clear reports.

### Database Design

Designed a relational database for a fictional training company.

* Identified suitable tables, columns and primary keys.
* Created relationships using foreign keys.
* Applied database normalisation principles to reduce duplication.
* Explained one-to-many relationships between tables.
* Compared relational databases with non-relational databases.
* Considered suitable storage methods for structured and unstructured data.

## SQL Skills Demonstrated

* `SELECT` and `DISTINCT`
* `WHERE`, `AND`, `OR` and `IN`
* `BETWEEN` and `LIKE`
* `ORDER BY` and `LIMIT`
* `COUNT`, `AVG` and other aggregate functions
* `GROUP BY`
* `INNER JOIN` and `LEFT JOIN`
* Multiple-table JOINs
* Primary and foreign keys
* Database relationships and schema design
* MySQL Workbench

## Key Learning

These projects strengthened my ability to translate business questions into SQL queries, combine information from related tables and produce accurate results that support data-driven decision-making.
